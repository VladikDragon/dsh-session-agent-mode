# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),

## [1.0.0] — 2026-11-20

Первый публичный релиз.

### Added

- Метка режима в слоте `sidebar.session.row.trailing` сразу после времени обновления:
  короткое имя пресета для встроенных режимов и имя из ростера Хоста для своих.
- Пустая строка для штатного пресета: сессии на `standard` не показывают ничего, и
  обычный список выглядит как до установки плагина.
- Подсказка с описанием пресета; без описания — предложение `hint` из словаря.
- Локали `ru`, `en`, `zh` с ключами `preset.standard`, `preset.ptc`, `preset.minimal`,
  `preset.cordis`, `hint` в namespace `sessionAgentMode`.
- Метка только читает `projectionValues.agentPreset` из уже загруженного списка сессий,
  поэтому не удерживает и не активирует сессию.
- Пакет оформлен как самостоятельный bundle: `dsh.bundle.patch` + `dsh.client`
  (`platform: "web"`, `inject` — `ui-session` и `ui-workspace`).
- Тестовый набор из 17 сценариев: макеты загрузчика модулей, `sessions`,
  `remote.agentPresets` и слотов; ASCII-чистота бандла, штатный пресет, встроенные и
  свои режимы, подсказка, число чтений ростера, повтор после ошибки, снятие подписок.

### Fixed

- Ростер пресетов больше не перезапрашивается на каждое изменение списка сессий, когда
  в нём остаётся идентификатор, которого Хост не назвал: запрос уходит один раз на
  идентификатор, а неудачное чтение забывает его и позволяет повторить попытку.
